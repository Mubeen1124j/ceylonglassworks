CEYLON GLASS WORKS WEBSITE
==========================

Files:
- index.html  = website
- style.css   = design
- script.js   = menu + quote form
- assets/     = supplied project photos
- sitemap.xml = Google sitemap template
- robots.txt  = crawler instructions

Before publishing:
1. Replace YOUR-DOMAIN.example in index.html, sitemap.xml and robots.txt with the final website domain.
2. Upload the whole folder to your chosen static host.
3. Add the published domain to Google Search Console.
4. Submit /sitemap.xml in Search Console.
5. Use URL Inspection -> Request indexing for the homepage.
